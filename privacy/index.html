Privacy

Last updated 19 November 2026. This describes the early version of the app, which is what you are using.

The short version

Your files stay in your browser. The app reads them on your computer, in memory, and nothing you load is sent to us or to anyone else. There is no account, no tracking and no advertising.

What happens to a file you load

  • A CSV you choose is read by a database that runs inside your browser, on your own computer. It is never uploaded.
  • It is held in memory only. Closing or reloading the page clears it. The app does not save your data between visits.
  • Columns that look like names, emails, phone numbers or addresses are blocked from being loaded for analysis. An email address in a file you give the app for assignment is turned into a keyed code in your browser, the address is dropped, and only the code is kept.
  • A ledger export is a file you save yourself. It holds your entries and their results. It does not hold email addresses, only the codes. A code is not anonymous, because an address can be guessed and checked against it, so keep the file as carefully as you would keep the list.

What the app stores or sends

  • It does not use cookies, local storage or any other store in your browser.
  • It makes no network requests of its own. The database files it needs are served from the same site.
  • Theme coding on the comments screen uses a small language model that runs in your browser. Only when you ask for it, the page downloads the model files, about 51 MB, from this same site. The app refuses to load them from anywhere else, does not keep them, and sends no comment text anywhere. Text you type there is redacted before the model sees it. Questions you type to the assistant on that screen are matched in your browser too, and go nowhere.
  • It has no analytics, no error reporting, no advertising and no outside fonts or scripts.
  • A shared link to a journeys or pipeline view holds only your filter and section choices, after a hash sign in the address. It never holds data or a name. A browser does not send the part after the hash to the server that hosts this page. Anything in a link that is not on a fixed list of allowed choices is ignored.

These statements are checked by an automated test that fails if the code starts using a storage, cookie or network feature.

What the website host can see

The site is delivered by a hosting service. Like any website, the host can see that a visit happened, with the usual details a web server records, such as the time, the page and the network address. It cannot see the files you load, because they never leave your browser. This app does not control what the host records.

Demo data

The demo data on the ledger, journeys and pipeline screens is generated in your browser. It contains no real people. Demo email addresses use a reserved domain, so none can reach anyone.

What this app does not do

  • It does not reliably remove personal names from text. It catches names after cues such as a sign-off and common first names, and misses others. Do not load free text that contains names you are not allowed to process.
  • It has not been tried on real customer data. Use the demo data to see how it works, and check with whoever is responsible for your customers' data before you use your own.
  • It is not legal advice, and it does not check whether you have consent to email anyone.
