What this tab holds

The ledger has 0 entries.

The Journeys, Pipeline, Comments and Data intake screens drop their own tables when you leave them. Only the ledger stays until the page reloads.

Keep the ledger

The ledger is the one thing worth keeping. Export it as a file before you clear the tab, and import the file again later on the Ledger screen.

Delete automatically after inactivity

Off until you turn it on. When it is on, this tab deletes everything it holds after a stretch with no clicks or key presses, and warns you for the last minute. It matters most on a computer other people use. It lives in this tab only, so a reload turns it off, as a reload already empties the tab.

Export the ledger first if you want to keep it. A file you exported stays where you saved it.

Delete everything in this tab

Drops every table and view in the in-browser database, which holds the ledger, loaded journeys, pipeline and comments, and then reloads the page. It cannot be undone. Files you exported stay where you saved them.
