Customer comments

What customers say, read next to what they did. Every comment here is synthetic and belongs to one synthetic customer, so each one can be joined to that customer’s journey. Text is redacted before it is stored or shown, and comments without consent are left out.

Names are only partly removed. The redaction rules catch emails, phone numbers, card numbers, street addresses, social security numbers and IP addresses. They catch a name after a cue such as “Thanks,” or “my name is”, and a common first name anywhere. Names typed in lowercase, a surname alone, and unusual names with no cue get through, so redacted text is not anonymous.
