Export and import

The ledger file can be imported again. The CSV is for a spreadsheet, one row per entry with its status and first result. It holds no design, no assignment and no address. A spreadsheet will show a quote before any text that starts like a formula, which is deliberate protection.

Import goes into an empty ledger. Times in an imported file are only as trustworthy as the file, because anyone can edit a file by hand.
